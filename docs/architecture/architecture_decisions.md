# Architecture Decision Records (ADRs)

Este archivo actúa como índice y guía para las Architecture Decision Records (ADRs) del proyecto.

## Propósito
Registrar decisiones arquitectónicas importantes de forma clara y rastreable: contexto, decisión, alternativas consideradas, consecuencias y fecha.

## Convención de archivos
- Cada ADR debe ser un archivo separado en docs/architecture/decision-records/ con nombre numerado: `architecture_decisions_xxx.md`.
